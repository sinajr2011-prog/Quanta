# Code of Conduct

Quanta is intended to be a respectful, constructive open-source project.

Contributors are expected to:

- communicate respectfully;
- focus criticism on code, designs, and ideas rather than people;
- avoid harassment, discrimination, threats, and deliberate disruption;
- protect private or sensitive information shared during project work;
- help keep discussions useful for students, educators, maintainers, and
  contributors.

Maintainers may remove contributions or restrict participation when conduct
repeatedly violates these expectations.
