QUANTA — Production Ready Release

این بسته برای استقرار عملیاتی سامانه آماده شده است.

ساختار UX هر شش پنل شامل منوی همبرگری، منوی تکمیلی و نوار دسترسی سریع پایین صفحه است.

منبع داده پنل‌ها API و دیتابیس است؛ داده نمایشی برای شاخص‌های اصلی پنل والد در رابط کاربری باقی نمانده است. در نبود داده، Empty State یا «—» نمایش داده می‌شود.

صفحات و بخش‌های قدیمی/آزمایشی که برای Production مناسب نبودند از بسته نهایی حذف شده‌اند.

قبل از Production:
1. از دیتابیس فعلی Backup بگیرید.
2. Upgrade دیتابیس را ابتدا روی نسخه تستی اجرا کنید.
3. اتصال MySQL/PHP و متغیرهای محیطی را تنظیم کنید.
4. همه شش نقش را با حساب واقعی تست کنید.
5. seed یا داده آزمایشی وارد دیتابیس واقعی نکنید.
6. کلید AI فقط در Backend تنظیم شود.
